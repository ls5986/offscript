Off Script support

Get help with games, saved prompts, browser play or the iOS beta. Android users can play online in a modern browser; no native Android app is needed. The native iPhone app requires iOS 16.4 or later.

Report a problem or ask a question

Open the Off Script issue tracker

Reports there are public. A GitHub account is required to post. Do not include player names, private-role cards, personal information, Apple passwords, or verification codes. Crop or redact screenshots before attaching them. For a privacy-sensitive request, ask for private contact instructions without posting the details.

A useful bug report includes:

  • The app version, device, and iOS/Android or browser version.
  • The game or screen you were using.
  • The steps that caused the problem.
  • What you expected and what actually happened.
  • A redacted screenshot, if it helps explain the problem.

If you are testing through TestFlight, you can also use TestFlight's feedback tools to send comments or screenshots to the developer. Apple handles that submission under its TestFlight privacy terms.

Common questions

Can I install it on an Android home screen?

Open Play online in Chrome and use the browser menu's Install app or Add to Home screen option if offered. On iPhone Safari, use Share, then Add to Home Screen. The installed web app opens directly to play. Install availability and wording depend on your browser; it is not an APK or an App Store install.

Do I need an account or internet connection?

There is no Off Script account. Games and prompts are bundled with the iOS app, so ordinary play works offline after installation. Installing or updating through TestFlight and opening support links need a connection. The web version needs a connection on its first visit so the app files can load and be cached. Open the game and allow caching to finish before relying on offline play. Your browser can remove cached files; private browsing and clearing site data can prevent offline access or remove saves.

How do I get another prompt or change ingredients?

In Studio, select the ingredients you want and use Generate Again. Optional composition combines the selected ingredients into a scene. Saved and locked words keep their original wording until you explicitly choose an available update for an editable copy.

How do I end a game or hide a game type?

Use End game in the game's footer to finish the party and open its saved recap. In Party, open the gear menu and choose Hide this game type to stop it appearing in future deals on this device. Choose games lets you include it again.

Why is some content unavailable?

Check Classroom clean and Optional 18+ format in Settings. Classroom clean keeps adult content hidden, including adult saved prompts. Party Night has its own group content opt-in. The content settings are not age verification. Any game can be skipped; drinking, touching, and personal disclosures are not required.

Does a rating automatically send feedback?

No. Ratings and notes are saved on your device. Report a problem lets you prepare a report, then use Share feedback on iOS or Copy feedback on the web. You decide where to send it. The prepared report does not automatically include player names or private roles, but an optional note can contain anything you type, so review it.

Can I sync or recover saved games on another device?

There is no app-managed cloud sync or browser-to-iPhone transfer. Native saves use local SQLite; browser saves use local browser storage. Device backups may include app data, but Off Script does not provide its own cloud-backup or restore service. Export local feedback shares feedback reports, not a backup of all saved games. A new website domain also has separate browser storage, so a Vercel deployment does not automatically import saves from an older site.

Can friends join the same game remotely?

Not through a shared online room. Party Night is designed for in-person play using one device. The online version runs the same local game on your browser; it does not synchronize different players' screens or saved sessions.

How do I remove saved names and sessions?

Open Settings, choose Clear all local data, and confirm. This resets saved user data while keeping the bundled catalog. It does not delete older device backups, reports already sent through TestFlight, public GitHub reports, or other copies you shared.

What should I try if the beta will not open or save?

Check TestFlight for an available current build, confirm your device has free storage, then close and reopen the app. Save an error message or a redacted screenshot for a report. Do not clear local data or delete the app as a first troubleshooting step: that can remove saved progress. For browser storage errors, allow site storage and close older Off Script tabs before retrying.

Why can I not hear cues or the New Choice bell?

Check device volume and silent settings. Spoken cues also depend on the app's sound setting and available device speech features. New Choice has a manual bell control for the separate caller. Visual and manual cues remain available; microphone access is not needed.
